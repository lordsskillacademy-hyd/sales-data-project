\# Sales Data Analytics Project



Comprehensive analytics project examining business sales data using Power BI and supplementary documentation.



\## Contents

\- `02-Project-Sales-Data.pdf` – Full project report (PDF)

\- `LSAproj.pbix` – Power BI dashboard file with all data modeling, visuals, and reports



\## Project Overview

\- Conducts deep analysis of sales transactions

\- Uses Power BI for dashboarding and self-service BI

\- PDF explains all findings, with supporting screenshots and insights



\## How to Use

\- Open the PDF for a written walkthrough of the project and insights

\- Open the `.pbix` file in Power BI Desktop to view, interact, or extend the dashboard
